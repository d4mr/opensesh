# Brand asset slots

Drop replacement assets here without changing application code:

- `logo.svg` — light-mode mark used in the sidebar, login, and email header
- `logo-dark.svg` — dark-mode mark
- `login-panel.jpg` — portrait login panel, approximately 1600×2000
- `og.png` — 1200×630 social card

The application renders its OS mark, event name, and greenroom tint when an image slot is absent.
