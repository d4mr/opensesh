---
title: "What is opensesh?"
description: "The open program OS for conferences — CFP, review, speakers, agenda, and embeds."
---

opensesh is the **open program OS for conferences** — an open-source (MIT) platform for running a conference program end to end: call for papers, submission review, speaker management, agenda building, and website embeds. You can use the hosted app at [app.opensesh.io](https://app.opensesh.io) or self-host the whole thing on Cloudflare Workers with a Postgres database.

## What it covers

The program lifecycle runs left to right — collect, decide, produce, publish — and each stage has a dedicated surface:

<Cards>
  <Card title="Call for Papers" href="/guides/call-for-papers">
    A form builder with conditional fields, plus a public submission wizard with draft saving and
    magic-link sign-in.
  </Card>
  <Card title="Submissions & review desk" href="/guides/submissions">
    Triage incoming submissions, record decisions, compose decision emails, and export everything to
    CSV.
  </Card>
  <Card title="Evaluation" href="/guides/evaluation">
    Review rounds with weighted criteria, blind mode, auto-distributed assignments, and AI-assisted
    reviews humans can override.
  </Card>
  <Card title="Sessions & content" href="/guides/sessions">
    Accepted submissions hand off into sessions, with a content approval workflow for slides and
    materials.
  </Card>
  <Card title="Speakers & speaker CRM" href="/guides/speakers">
    A per-event speaker directory plus an organization-level CRM with pipeline stages, tags,
    segments, campaigns, CSV import, and duplicate merge.
  </Card>
  <Card title="Speaker portal" href="/guides/speaker-portal">
    A self-serve portal where speakers complete tasks, upload deliverables, and edit their profile
    with admin approval.
  </Card>
  <Card title="Agenda" href="/guides/agenda">
    A schedule editor with conflict detection, AI draft generation, and publish/unpublish control.
  </Card>
  <Card title="Widgets & embeds" href="/guides/widgets">
    Embeddable sessions, speakers, gallery, agenda, and itinerary views with a theme API, plus a
    JSON feed and ICS calendar export.
  </Card>
  <Card title="Email" href="/guides/email">
    Templates, campaigns, reminders, magic links, and a demo inbox for testing.
  </Card>
  <Card title="Integrations" href="/guides/integrations">
    One-way import of speakers and attendees from Accelevents into the speaker CRM.
  </Card>
  <Card title="Workspace & roles" href="/guides/workspace">
    Organizations, members, and event-scoped roles.
  </Card>
</Cards>
