# Events

7 operations. All requests need an `Authorization: Bearer osk_...` header — see the [API overview](/api) for authentication and conventions.

## List events
`GET /events`
```bash
curl https://app.opensesh.io/api/v1/events \
  -H "Authorization: Bearer osk_..."
```
---

## Create an event
`POST /events`
#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes |  |
| `type` | `"conference" \| "summit" \| "meetup"` | yes |  |
| `timezone` | `string` | yes |  |
| `startsAt` | `string` | yes |  |
| `endsAt` | `string` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"...","type":"conference","timezone":"...","startsAt":"...","endsAt":"..."}'
```

## Create or update a library item
`POST /events/\{eventId\}/library`
Pass id: null to create; an existing id updates that item.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `kind` | `"track" \| "format" \| "room" \| "tag" \| "level"` | yes |  |
| `id` | `string \| null` | yes |  |
| `name` | `string` | yes |  |
| `color` | `string \| null` | no |  |
| `durationMinutes` | `number \| null` | no |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/library \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"kind":"track","id":"...","name":"..."}'
```
