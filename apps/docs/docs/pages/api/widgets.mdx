# Widgets

4 operations. All requests need an `Authorization: Bearer osk_...` header — see the [API overview](/api) for authentication and conventions.

## Get the published program
`GET /events/\{eventId\}/program`
The public program feed: accepted sessions with approved content, speakers, tracks, and the published agenda. Same data the embeds render.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

```bash
curl https://app.opensesh.io/api/v1/events/eventId/program \
  -H "Authorization: Bearer osk_..."
```

## Create an embed widget
`POST /events/\{eventId\}/widgets`
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes |  |
| `view` | `"sessions" \| "speakers" \| "speaker_gallery" \| "agenda" \| "itinerary"` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/widgets \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"...","view":"sessions"}'
```
---

## Update an embed widget
`PATCH /events/\{eventId\}/widgets/\{widgetId\}`
Full widget update: name, view, enabled flag, and every option (filters, theme, visible fields, custom CSS).
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |
| `widgetId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes |  |
| `view` | `"sessions" \| "speakers" \| "speaker_gallery" \| "agenda" \| "itinerary"` | yes |  |
| `enabled` | `boolean` | yes |  |
| `options` | `object` | yes |  |

```bash
curl -X PATCH https://app.opensesh.io/api/v1/events/eventId/widgets/widgetId \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"...","view":"sessions","enabled":true,"options":{}}'
```
