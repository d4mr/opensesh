# CRM

12 operations. All requests need an `Authorization: Bearer osk_...` header — see the [API overview](/api) for authentication and conventions.

## List CRM contacts
`GET /contacts`
The organization-wide speaker CRM directory (contacts persist across events). Supports a q= substring filter on name, email, and company.
#### Query parameters

| Name | Required | Notes |
| --- | --- | --- |
| `q` | no | Case-insensitive filter on name, email, company. |

```bash
curl https://app.opensesh.io/api/v1/contacts \
  -H "Authorization: Bearer osk_..."
```

## Bulk import contacts
`POST /contacts/import`
Idempotent by email. behavior: "update" refreshes existing contacts, "skip" leaves them untouched. Returns created/updated/skipped counts with a per-row outcome list.
#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `behavior` | `"update" \| "skip"` | yes |  |
| `rows` | `object[]` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/contacts/import \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"behavior":"update","rows":[]}'
```
