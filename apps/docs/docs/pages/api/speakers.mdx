# Speakers

6 operations. All requests need an `Authorization: Bearer osk_...` header — see the [API overview](/api) for authentication and conventions.

## List event speakers
`GET /events/\{eventId\}/speakers`
The speaker directory: profile readiness, workflow status, task progress, and sessions per speaker.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

```bash
curl https://app.opensesh.io/api/v1/events/eventId/speakers \
  -H "Authorization: Bearer osk_..."
```

## Create or update a speaker
`POST /events/\{eventId\}/speakers`
Pass id: null to create; an existing contact id updates that speaker.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | `string \| null` | yes |  |
| `firstName` | `string` | yes |  |
| `lastName` | `string` | yes |  |
| `email` | `string` | yes |  |
| `title` | `string \| null` | yes |  |
| `company` | `string \| null` | yes |  |
| `bio` | `string \| null` | yes | CommonMark markdown; raw HTML renders as literal text |
| `linkedinUrl` | `string \| null` | yes |  |
| `twitterUrl` | `string \| null` | yes |  |
| `websiteUrl` | `string \| null` | yes |  |
| `dietaryRequirements` | `"none" \| "vegetarian" \| "vegan" \| "gluten_free" \| "other"` | yes |  |
| `tshirtSize` | `"XS" \| "S" \| "M" \| "L" \| "XL" \| "XXL" \| null` | yes |  |
| `travelLogistics` | `string \| null` | yes |  |
| `workflowStatus` | `"invited" \| "onboarding" \| "confirmed" \| "ready" \| "declined"` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/speakers \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"id":"...","firstName":"...","lastName":"...","email":"...","title":"...","company":"...","bio":"...","linkedinUrl":"...","twitterUrl":"...","websiteUrl":"...","dietaryRequirements":"none","tshirtSize":"XS","travelLogistics":"...","workflowStatus":"invited"}'
```
