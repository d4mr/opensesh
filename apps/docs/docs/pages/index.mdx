# What is opensesh?

opensesh is the **open program OS for conferences** — an open-source (MIT) platform for running a conference program end to end: call for papers, submission review, speaker management, agenda building, and website embeds. You can use the hosted app at [app.opensesh.io](https://app.opensesh.io) or self-host the whole thing on Cloudflare Workers with a Postgres database.

## What it covers

- **Call for Papers** — build submission forms with conditional fields, publish a public submission wizard with draft saving and magic-link sign-in for submitters.
- **Submissions & review desk** — triage incoming submissions, record decisions, compose decision emails, and export everything to CSV.
- **Evaluation** — review rounds with weighted criteria, blind mode, reviewer assignment with auto-distribute, and AI-assisted reviews that humans can override.
- **Sessions & content** — accepted submissions hand off into sessions, with a content approval workflow for slides and materials.
- **Speakers** — a per-event speaker directory plus an organization-level speaker CRM with pipeline stages, tags, segments, campaigns, CSV import, and duplicate merge.
- **Speaker portal** — a self-serve portal where speakers complete tasks, upload deliverables, and edit their profile (with admin approval).
- **Agenda** — a schedule editor with conflict detection, AI draft generation, and publish/unpublish control.
- **Widgets & embeds** — embeddable sessions, speakers, gallery, agenda, and itinerary views for your conference website, with a theme and custom-CSS API, plus a JSON feed and ICS calendar export.
- **Email** — templates, campaigns, reminders, magic links, and a demo inbox for testing.
- **Integrations** — one-way import of speakers and attendees from Accelevents into the speaker CRM.
- **Workspace** — organizations, members, and event-scoped roles.
