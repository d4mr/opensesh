```bash
  -H "Authorization: Bearer osk_..."
```

## Generate an AI agenda draft
`POST /events/{eventId}/agenda/drafts`
Anthropic-backed schedule proposal from your criteria and free-text rules (max 12). Requires ANTHROPIC_API_KEY on the deployment.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `name` | `string` | yes |  |
| `criteria` | `object` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/agenda/drafts \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"...","criteria":{}}'
```

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `submissionId` | `string` | yes |  |
| `roomId` | `string \| null` | yes |  |
| `startsAt` | `string \| null` | yes |  |
| `endsAt` | `string \| null` | yes |  |

```bash

  -H "Authorization: Bearer osk_..." \
```
