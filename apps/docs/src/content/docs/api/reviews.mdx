## Override an AI review score
`POST /events/{eventId}/ai-review-override`
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `resultId` | `string` | yes |  |
| `score` | `number` | yes |  |
| `reason` | `string` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/ai-review-override \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"resultId":"...","score":1,"reason":"..."}'
```

Pass roundId: null to create. Criteria replace the round's existing scorecard.

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |

| `name` | `string` | yes |  |
| `opensAt` | `string` | yes |  |
| `closesAt` | `string` | yes |  |
| `blind` | `boolean` | yes |  |
| `position` | `number` | yes |  |
| `criteria` | `object[]` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/review-rounds \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"roundId":"...","name":"...","opensAt":"...","closesAt":"...","blind":true,"position":1,"criteria":[]}'
```
