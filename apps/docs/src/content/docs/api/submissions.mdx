## Create a session directly
`POST /events/{eventId}/sessions`
Creates an accepted session without a CFP submission — the manual-add path. Speakers must already be event contacts.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `title` | `string` | yes |  |
| `description` | `string \| null` | yes | CommonMark markdown; raw HTML renders as literal text |
| `formatId` | `string \| null` | yes |  |
| `speakerIds` | `string[]` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/sessions \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"title":"...","description":"...","formatId":"...","speakerIds":[]}'
```

## List submissions
`GET /events/{eventId}/submissions`
The review-desk view of submissions: status, code, title, tracks, format, speakers, rating, review counts.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Query parameters

| Name | Required | Notes |
| --- | --- | --- |
| `kind` | no | The submission stage: "abstract" (CFP inbox) or "session" (default). |
| `status` | no | Filter to one status (pending, accepted, declined, …). |

```bash
curl https://app.opensesh.io/api/v1/events/eventId/submissions \
  -H "Authorization: Bearer osk_..."
```

| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |

## Accept or decline submissions
`POST /events/{eventId}/submissions/decide`
Applies the decision to every submission id, snapshots accepted content for the program, and sends decision emails. Set confirmRedecide to change already-decided submissions.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `submissionIds` | `string[]` | yes |  |
| `decision` | `"accept" \| "decline"` | yes |  |
| `feedback` | `string` | yes |  |
| `confirmRedecide` | `boolean` | no |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/submissions/decide \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"submissionIds":[],"decision":"accept","feedback":"..."}'
```
