## Send a speaker campaign
`POST /events/{eventId}/campaigns`
Sends a templated or free-form email to the given event contacts and records the campaign.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `templateId` | `string \| null` | yes |  |
| `subject` | `string` | yes |  |
| `body` | `string` | yes |  |
| `contactIds` | `string[]` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/campaigns \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"templateId":"...","subject":"...","body":"...","contactIds":[]}'
```
