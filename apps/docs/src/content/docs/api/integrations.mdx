## Get the Accelevents connection
`GET /events/{eventId}/integrations/accelevents`
The stored API key never round-trips — only its masked prefix.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

```bash
curl https://app.opensesh.io/api/v1/events/eventId/integrations/accelevents \
  -H "Authorization: Bearer osk_..."
```

## Connect or update Accelevents
`PUT /events/{eventId}/integrations/accelevents`
Set apiKey to the literal "demo-accelevents-key" with eventUrl "demo" to use the bundled demo connection.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `eventUrl` | `string` | yes |  |
| `apiKey` | `string \| null` | yes |  |
| `importAttendees` | `boolean` | yes |  |

```bash
curl -X PUT https://app.opensesh.io/api/v1/events/eventId/integrations/accelevents \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"eventUrl":"...","apiKey":"...","importAttendees":true}'
```

## Run a one-way Accelevents sync
`POST /events/{eventId}/integrations/accelevents/sync`
Pulls speakers (linked to the event with full profiles) and optionally attendees (tagged CRM contacts). Idempotent by email; nothing is ever written back to Accelevents.
#### Path parameters

| Name | Required | Notes |
| --- | --- | --- |
| `eventId` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/events/eventId/integrations/accelevents/sync \
  -H "Authorization: Bearer osk_..."
```
