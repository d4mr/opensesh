## Get the pipeline board
`GET /pipeline`
Stages with their cards, in board order.
```bash
curl https://app.opensesh.io/api/v1/pipeline \
  -H "Authorization: Bearer osk_..."
```

## Add a contact to the pipeline
`POST /pipeline/cards`
#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `organizationContactId` | `string` | yes |  |
| `stageId` | `string` | yes |  |
| `note` | `string \| null` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/pipeline/cards \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"organizationContactId":"...","stageId":"...","note":"..."}'
```

## Create or update a pipeline stage
`POST /pipeline/stages`
#### Request body

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | `string \| null` | yes |  |
| `name` | `string` | yes |  |
| `semanticStatus` | `"open" \| "won" \| "lost"` | yes |  |
| `position` | `number` | yes |  |

```bash
curl -X POST https://app.opensesh.io/api/v1/pipeline/stages \
  -H "Authorization: Bearer osk_..." \
  -H "Content-Type: application/json" \
  -d '{"id":"...","name":"...","semanticStatus":"open","position":1}'
```
